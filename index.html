Red Square Platformer

Move the red square, jump across the platforms, collect the star, and reach the green flag.

Move: ← → or A / D · Jump: Space / ↑ / W

What this teaches you

  • canvas draws the player, platforms, and background.
  • Keyboard input changes the player's horizontal velocity.
  • Gravity changes vertical velocity; jumping gives it an upward push.
  • Collision checks stop the square inside platforms and let it land.
  • The game loop updates the world, then draws each frame.
